perlscript-web

Perl is the UI.

A deliberately small Perl 1-shaped language for the browser. DOM elements are filehandles. Events are streams. Output stays text.

Run the BBS Read the profile

HTML outside. Perl inside.

Load one browser bundle, open a DOM filehandle, and print. No framework owns the page.

hello.html
<script src="./dist/perlscript-web.min.js"></script>
<output id="hello"></output>
<script type="text/perl">
open HELLO, ">dom:#hello";
select HELLO;
print "Hello from Perl.";
</script>
